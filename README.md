# 🚀 Crawler & LLM Classifier Dashboard

Полнофункциональный веб-дашборд для наблюдения за работой связки **«парсер поисковой выдачи → LLM-классификатор»** и выдачи результатов клиентам, полностью реализованный по техническому заданию [TZ_dashboard.md](file:///C:/Users/Bogdan/Downloads/Telegram%20Desktop/TZ_dashboard.md).

## 🖥 Реализованные разделы и экраны

### 1. Главная (Дашборд)
- **10 KPI-плиток (сетка 5×2)**: Запросов отработано, Найдено ссылок, Обработано нейросетью, Подходящих, Конверсия, В очереди, Ошибок, Уникальных доменов, Скорость (/мин), Среднее время обработки. Каждая плитка содержит значение, подпись, дельту к предыдущему периоду (↑ +12% зелёным / ↓ −8% красным) и мини-спарклайн.
- **Основной график**: Двухлинейный минутный график («Найдено ссылок» vs «Подходящих»), адаптивная гранулярность (1 мин, 5 мин, 1 час), интерактивный тултип.
- **Воронка**: 5 ступеней конверсии с абсолютными числами и процентами перехода между этапами.
- **Гистограмма оценок (0–10)**: Столбцы с приглушением ниже порога клиента, вертикальная метка порога, интерактивный клик по столбцу для мгновенной выборки ссылок с данным баллом.
- **Топы**: 3 переключаемые таблицы (Топ запросов, Топ доменов, Худшие запросы с нулевым числом подходящих).
- **Разбивки**: Горизонтальные бары по категориям (`PMS`, `Channel Manager`, `Booking Engine`, `RMS`, `OTA`, `Unrelated`) и регионам (22+ страны).
- **Живая лента находок (WebSocket)**: Поток подходящих ссылок в реальном времени с 2-секундной анимацией подсветки, цветными бейджами оценки и **кнопкой паузы** со счётчиком накопленных ссылок.

### 2. Проекты (`/projects`)
- Карточки проектов клиента с ключевыми метриками (число запросов, оценено, подходящих, дата создания, статус).
- Создание нового проекта, переименование, архивирование.
- Клик по проекту фильтрует поисковые запросы и ссылки.

### 3. Запросы (`/queries` и `/queries/:id`)
- Таблица поисковых запросов с сортировкой, текстовым поиском, фильтрами по статусу (`active`, `paused`, `done`, `stopped`) и проектам.
- Модальное окно добавления запроса с мультиселектом регионов (22 региона или `Global wt-wt`).
- Кнопки паузы/возобновления и снятия с обхода.
- **Детальная страница запроса (`/queries/:id`)**: персональные KPI запроса, таблица разбивки по регионам, гистограмма оценок и последние ссылки.

### 4. Реестр ссылок (`/links`)
- Полнотекстовый поиск по URL, заголовкам, сниппетам и тегам.
- **Бесконечный скролл** на основе Keyset-пагинации по `(classified_at DESC, id DESC)` с индикацией скелетонов при догрузке.
- Раскрывающиеся аккордеоны строк с полным описанием страницы по тегам (`page_tags`) и сниппетом.
- Панель фильтров: период, проект, запрос, диапазон оценки (min..max), домен, категория, регион.
- Счётчик «Найдено: N записей» и кнопка экспорта в CSV.

### 5. Настройки клиента (`/settings`)
- **Слайдер порога оценки (6..10)** с предупреждениями при `< 7` и `10`, пояснением о независимости расхода бюджета и мгновенным применением.
- **Прогресс-бары бюджета**: Сырые запросы и Нейросетевые вызовы (LLM) с предупреждениями 80% (жёлтый) и 95% (красный).
- Форма смены собственного пароля.

### 6. Конструктор промпта (`/prompt`)
- Вкладки **Этап 1 (Быстрый фильтр)** и **Этап 2 (Глубокий скоринг)**.
- Редактируемые блоки: `target_description` (до 1500 симв.), `exclusions` (до 1500 симв.), `categories` (до 12 шт.), `reference_sites` (до 30 сайтов с описаниями).
- Сплит-предпросмотр итогового собранного системного промпта в реальном времени.
- История версий с возможностью отката в один клик.

### 7. Мониторинг системы (`/monitoring`, только Admin и Manager)
- **Карточки служб**: `crawler`, `targeted_crawler`, `link_extractor`, `scorer`. Статус определяется по времени последней записи (зелёный <2 мин, жёлтый 2–10 мин, красный >10 мин).
- **Очереди**: размер очереди Этапа 1 и Этапа 2, график динамики очередей и время отставания скорера (`now() - min(found_at)`).
- **Ресурсы сервера (185.86.76.127)**: CPU (общая загрузка и мини-бары по 8 ядрам), RAM (MB / %), NVMe Диск (свободно / всего), Сетевой трафик (MB/s).
- **Два GPU NVIDIA RTX 4090**: температура, загрузка ядра (%), занятая VRAM.
- **8 инстансов Ollama (порты 11434–11441)**: статус, пинг в миллисекундах, загруженная модель, активные вызовы.
- **Управление службами (Admin)**: кнопки Старт/Стоп/Рестарт софта и перезагрузка конфигурации промпта с подтверждением.

### 8. Администрирование (`/admin`, Admin и Manager)
- Управление пользователями: создание клиентов, блокировка/разблокировка, начисление бюджетов с указанием причины.
- **Журнал действий (Audit Log)**: фиксация всех входов, смены порогов, правок промптов, пополнений бюджета и команд управления с фильтрами по автору и действию.

### 9. Экспорт данных в CSV
- Формирование CSV-файла с заголовком **UTF-8 с BOM** (`\uFEFF`) для идеальной совместимости с Microsoft Excel без кракозябр.
- Разделитель строк `\r\n` (CRLF), экранирование по стандарту RFC 4180.
- Все даты и временные метки отформатированы по часовому поясу **Europe/Kyiv** (`YYYY-MM-DD HH:MM:SS`).
- Режимы «Текущая выборка с фильтрами» и «Все подходящие ссылки».

## 🚀 Запуск и разработка

### 1. Запуск в режиме продакшн / Standalone
```bash
cd crawler-dashboard
npm run build
npm start
```
Сервис доступен по адресу: **`http://localhost:3001`**

### 2. Запуск в режиме разработки (Hot-reload)
```bash
cd crawler-dashboard
npm run dev
```
- Frontend (Vite Dev Server): **`http://localhost:3000`**
- Backend & WebSocket: **`http://localhost:3001`**
